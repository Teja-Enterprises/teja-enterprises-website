FREE HOSTING PLAN:
Recommended: GitHub Pages.
1. Create/sign in to GitHub.
2. Create a new public repository (for example: teja-enterprises-website).
3. Upload all files in this folder, keeping the assets folder intact.
4. In repository Settings → Pages, choose "Deploy from a branch", select the main branch and root folder, then save.
5. GitHub will provide a temporary pages address.
6. In Squarespace, open teja-enterprises.com → DNS and add the GitHub Pages custom-domain records GitHub gives you.
7. In GitHub Pages, enter teja-enterprises.com as the custom domain and enable HTTPS when available.
8. Keep your Google Workspace MX records unchanged so rudra@teja-enterprises.com continues working.
